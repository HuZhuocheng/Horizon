# Horizon — 企业经营风险洞察助手

## 目标用户
银行客户经理、中小贷风控专员、投研助理等一线业务人员。

## 业务背景 & 痛点
中小微企业信贷前期尽调中，风控人员面临以下真实行业痛点：
1. **资料多源分散**：人工阅读 PDF 财报、扫描件合同耗时久。
2. **校验易遗漏**：需要对照信贷风控规则做校验，人工容易遗漏风险点。
3. **大量重复性劳动**：信息摘录、指标计算、风险标记占用大量时间。
4. **缺少自动化流程**：读材料→提取指标→规则校验→风险高亮→输出尽调摘要报告，大多依赖人工拼接。

**核心原则：本系统不做自动放贷、不做信用打分决策，只做业务辅助。最终风险判断交给人，完美规避金融合规红线。**

## 核心定位
**人做最终决策，Agent 做资料整理、指标提取、规则校验、风险提示辅助。**

## 使用步骤提示
1. **启动服务**：在终端运行 `streamlit run app.py`，浏览器将自动打开系统界面。
2. **体验内置演示**：在左侧边栏点击“一键运行内置示例”，系统将自动加载示例文件并展示完整的尽调分析报告。
3. **配置大模型（可选）**：在左侧边栏的“API 设置”中输入兼容的大模型接口（如阿里云通义千问等），即可在右侧体验真实的智能多轮对话分析。
4. **自定义文件测试**：您也可以手动上传您自己的测试文件，点击“开始自动化尽调”来体验系统的分析能力。

## Agent 完整任务闭环
本工作流演示了完整的 Agent 自动化处理流程：
1. **任务接收**：上传企业材料（财报、工商报告、裁判文书等）。
2. **任务拆解 & 流程编排**：
   - 子任务 1：多模态文档解析（提取经营指标、涉诉等信息）。
   - 子任务 2：调用风控规则知识库进行规则匹配。
   - 子任务 3：检索外部公开知识库（行业基准阈值）。
   - 子任务 4：风险标记（高亮异常指标、负面记录等）。
3. **多轮交互**：风控人员可追问细节，Agent 结合大语言模型 (LLM) 重新执行分析或解答疑问。
4. **结果交付**：输出结构化尽调简报（包含企业概况、财务指标、规则校验结果、风险清单等）。

## 核心特性
1. **面向信贷尽调完整业务闭环**：不仅是单点问答，而是编排成完整的 Agent 工作流。
2. **可配置风控规则知识库**：业务人员可新增/修改风控规则，适配不同银行产品。
3. **大模型 (LLM) 智能驱动**：支持对接真实的 LLM（如 OpenAI、DeepSeek、Qwen 等），实现智能化的资料解析和多轮问答。
4. **强合规约束设计**：所有风险点绑定原始材料出处，可溯源，不生成信贷决策。

## 数据与合规边界说明
- **隐私保护**：所有文件本地处理；系统本身不留存真实企业敏感数据。
- **风险边界**：输出仅供业务参考，不构成信贷建议，所有结论需人工复核。

## 快速启动

1. 安装依赖：
```bash
pip install -r requirements.txt
```

2. 运行应用：
```bash
streamlit run app.py
```

*(注：系统支持在前端界面配置 LLM API Key，以体验真实的 AI 分析能力；若不配置，系统将默认运行本地规则引擎演示工作流。)*
